# Hypergraph Computation Tools

## Available Tools

1. **Hypergraph Studio** — Create, edit, visualize, and analyze hypergraphs, including edge mappings with 1-based edge indexing.

2. **Hypergraph Isomorphism & Spectral Analyzer** — Compare hypergraphs for structural equivalence and investigate their spectral properties.

3. **Hypergraph Edge Orbits** — Compute edge orbits under vertex permutations and visualize their relationships.

4. **Hypergraph Coloring Solver** — Find weak and strong vertex colorings and search for the minimum number of colors.

5. **Transversal & Hitting-Set Solver** — Find minimum transversals and enumerate minimal vertex sets that intersect every hyperedge.

6. **Automorphism Group Explorer** — Find hypergraph symmetries, calculate the automorphism group order, and identify vertex orbits.

7. **Matching & Packing Solver** — Find maximum matchings of pairwise disjoint hyperedges and enumerate maximal matchings.
